# Command Center

## Purpose
The Command Center screen is a digital ecosystem health overview monitoring performance, user sessions, active counts, and platform-specific metrics for the club's mobile fan app.

## Metrics on this screen

- `app_downloads`
- `matchday_visits`
- `pct_android`
- `organic_launch_visits`
- `app_push_visits`
- `deeplink_visits`
- `other_channel_visits`
- `session_time_avg`
- `heavy_users`
